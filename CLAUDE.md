## Estado da implementação (v0.2)
Migrado para Next.js 16 + TS em `src/` (piloto em `legacy/`). Next 16: use `proxy.ts` (não middleware) e `params` como Promise; consulte `node_modules/next/dist/docs/`. Regras de negócio puras ficam em `src/lib/domain` com testes em `tests/`; nenhuma regra nova sem teste. Migrations em `supabase/migrations` (testadas com PGlite em `tests/db.test.ts`; adicione casos de RLS para cada tabela nova). Toda rota autenticada usa `route()` e `owned()` de `src/lib/api.ts`. Chaves só via `src/lib/env.ts` (server-only). Antes de commit: `npm run typecheck && npm test && npm run build`.
